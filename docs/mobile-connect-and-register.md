# 手机连接与账号注册

## 同一 Wi-Fi 的本机调试

1. 在电脑的完整项目目录运行 `start-local.cmd`，保持电脑开机、后端运行。
2. 重新用微信开发者工具预览小程序并扫码。电脑使用 `http://127.0.0.1:8080`；手机需要电脑的 Wi-Fi IPv4 地址，例如 `http://192.168.1.10:8080`。
3. 手机小程序进入“我的 → 服务连接”。若预览包包含启动脚本生成的本机地址，点击“连接本机调试服务”；否则手动填写电脑地址，选择真实服务并保存，再点击“连接测试”。
4. “已配置服务器”只表示保存了地址；“连接成功”表示健康检查和本项目后端身份检查均通过。

`127.0.0.1` 和 `localhost` 在手机上指的是手机自身，不能用来访问电脑。新版本会在发请求前明确提示，避免一直显示模糊的“未连接”。启动脚本生成的地址仅适合当前局域网；Wi-Fi 或电脑 IP 变化后需重新运行启动脚本并更新预览包或手动保存新地址。

## 用手机浏览器定位问题

展开服务连接，点击“复制浏览器检测地址”，在手机浏览器打开。

| 浏览器结果 | 下一步 |
| --- | --- |
| `/actuator/health` 返回 `status: UP` | 手机能访问电脑。若小程序失败，核对其保存的地址，并查看连接测试中的微信错误说明 |
| 网页超时或无法连接 | 检查后端是否启动、电脑 IP 是否正确、防火墙或 Wi-Fi 客户端隔离；同一 Wi-Fi 不保证设备可以互访 |
| 返回其他网页或 404 | 地址/端口/路径可能错误；健康检查通过后，小程序还会校验 `/assistant/status` 是否为本项目服务 |

如果微信返回 `url not in domain list`，开发版可在手机小程序右上角菜单开启调试后重新进入；正式版应使用有效 HTTPS 证书并在微信公众平台配置合法 `request` 域名。电脑开发者工具的“跳过域名校验”不能作为线上连接方案。局域网 IP 请求与线上域名配置应分开排查，不能把所有失败都归为域名问题。

如果是 iPhone，浏览器能打开而微信仍不能连接，还应在“设置 → 隐私与安全性 → 本地网络”中允许微信访问。Safari 与微信的权限独立，不能以浏览器成功推断微信已获授权。参见 [Apple 本地网络权限说明](https://support.apple.com/zh-cn/102229)。

网络说明参考：[微信小程序网络文档](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[腾讯官方网络规范](https://intl.cloud.tencent.com/document/product/1219/61745)。

## 注册与登录

1. 进入“我的 → 登录/注册”，切换“注册账号”。演示模式也保留入口，并提示先连接真实服务。
2. 输入账号（1–64 字）、密码（8–64 位）并确认密码。密码还需满足后端 BCrypt 的字节上限，过长的汉字/表情会在提交前提示。
3. 注册成功后自动回到登录表单，账号保留、两次密码输入清空；输入密码登录即可查询自己的观察记录。
4. 重复账号、密码不一致、网络异常会在表单内提示，不会把 HTTP 200 中的错误文本当作成功，也不会把注册成功文本保存为登录令牌。

注册复用既有 `POST /user/register`，只提交 `username` 和 `password`；普通账号角色和密码哈希仍由后端处理。没有增加微信一键登录、验证码、找回密码或新鉴权协议。新注册账号没有历史观察记录，流程体验也不会生成真实健康记录。
