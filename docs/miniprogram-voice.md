# 小程序语音联调

## 陪伴与观察

- **陪伴**。切换到接口联调模式后，点击输入框左侧麦克风。首次录音会说明上传用途并请求微信隐私及麦克风授权。点「结束」后转写，确认文字再发送。已有草稿会保留并合并，单段最长 60 秒。录制中可取消，切页、收起对话和录音中断会结束当前语音操作。
- **朗读**。真实回复可分段自动朗读，可关闭该开关，也可对单条回答朗读、暂停、继续或停止。发送新消息会中止当前播放。Edge 普通话合成需要电脑联网，启用朗读会把回复文本发往在线语音服务。
- **观察与记录**。联调模式下通过「我的」登录。确认同意后可看图录音，最长 300 秒，支持暂停、继续、取消、试听、重录与提交。上传结果不明时会核对账号录音列表再提供重试。记录页可下载试听、暂停、继续、停止、删除已上传录音或用现有接口发起分析，仍通过现有报告面板查看任务。完整异步分析及报告依赖正式筛查服务。
- **录音格式**。手机请求单声道 16 kHz PCM WAV，客户端测量真实时长并检查容器和大小。对旧项目确认的特定 44 字节长度错误，仅修正 RIFF 和 data 长度字段。开发者工具实测会把 WebM 保存为 WAV 后缀。陪伴在工具环境检测 WebM 容器签名并按真实扩展名上传，观察录音须用手机生成标准 PCM WAV。上传及播放临时文件随流程清理。

旧项目位于 `D:/ChromeDownloads/yisheng-guardian-main/yisheng-guardian-main`。其小程序实现包括陪伴转写、数字人语音朗读、观察录音与消息/报告中的音频管理。当前应用已包含同一套 Java 转写、存储与观察接口，本次接回小程序能力，并沿用团队远端分支的语音代理和本地工作进程。聊天沿用当前单轮接口和聊天面板，观察与记录沿用四个页面入口和玻璃风格。当前网页和数字人媒体接口继续服务其现有调用方。

## Windows 启动和设备验证

1. 在仓库根目录运行 `./start-local.cmd -Build`。如已运行本项目后端，先用 `./stop-local.ps1` 停止。首次使用需安装 Python 3.10+，启动器下载 faster-whisper small 和 Python 依赖到 `.runtime`。
2. 开发者工具导入 `miniprogram` 目录。开发机使用 `http://127.0.0.1:8080`，手机通过「我的 → 服务连接」填写电脑 Wi-Fi IPv4 地址及 8080 端口并检查连接。电脑和手机需要位于可互访的网络。
3. 在微信开发者工具点「真机调试 → 二维码真机调试」，选择 Android/鸿蒙或 iOS。扫码连接后分别验收授权拒绝与恢复、连续录音、取消、通话中断、切后台、弱网、WAV 转写、试听与朗读音量。二维码过期后在同处重新生成。正式版须在公众平台配置隐私保护指引与 HTTPS 合法域名。
4. 查看 `/actuator/health`、`/actuator/health/liveness`、`/actuator/health/readiness` 和 `/assistant/voice/status`。返回 `asrReady: true` 表示模型已加载。合成可用性须通过实际播放或请求确认。

默认语音工作进程只监听 `127.0.0.1:5010`。可通过 `PYTHON_TRANSCRIPTION_URL` 接入现有识别服务，`APP_VOICE_URL` 设置合成代理目标，`VOICE_WHISPER_MODEL` 设置本机识别模型，`VOICE_TTS_PROXY` 覆盖合成代理（`direct` 表示直连）。有独立转写服务时，确保 Java 与该服务访问相同的音频存储。模型凭据使用本机环境配置。

| 接口 | 用途 |
|---|---|
| `POST /assistant/speech/transcribe` | multipart `file`，返回 `transcription` |
| `POST /assistant/chat` | 发送确认后的文字，沿用现有单轮协议 |
| `GET /assistant/voice/status` | 语音进程与模型状态 |
| `POST /assistant/voice/synthesize` | JSON `{text}`，返回 `audio/mpeg` |
| `POST /audio/upload` | 登录、同意和标准 PCM WAV 录音 |
| `GET /audio/my`、`GET /audio/file/{name}`、`DELETE /audio/{name}` | 本人录音列表、下载、删除 |
| `POST /api/v1/audios/{audioId}/screenings` | 使用已有录音发起观察分析 |
