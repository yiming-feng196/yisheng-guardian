# 忆声陪伴：当前版本

更新日期：2026-11-05。

## 产品定位

面向不同年龄用户提供日常情感陪伴与认知健康观察。数字人支持生活交流、
心情和压力支持、故事与放松练习；认知筛查保留为独立功能，不将普通聊天强行归入疾病问答。
情绪识别只用于交互提示，语音认知观察只提供辅助信息，均不能替代专业诊断。

## 当前源码

- `backend/`：Spring Boot 业务 API、账号和会话、日常陪伴与认知知识路由、后台任务、PDF，以及当前前端。
- `backend/src/main/resources/static/`：当前界面、麦克风处理、音量控件及情绪滤波器。
- `screening-service/`：Python 语音转写、描述性特征提取和筛查任务流水线。
- `digital-human-service/`：数字人中文语音、音频获取及可选 SadTalker 视频生成。
- `vision-service/`：YuNet 人脸检测和七类表情识别；包含两个小型 ONNX 模型。
- `deploy/jetson/`：Jetson 前端代理、相机、I²S 音频路由、PulseAudio 和浏览器自启动配置。
- `compose.yaml`、`.env.docker.example`：本机容器部署及环境变量模板。
- `frontend/`：早期前端参考，不是当前运行入口。

## 双机部署

工作站默认有线地址为 `192.168.55.1`，运行业务后端（8080）、数字人语音（8091）和视觉服务（8092）。
Jetson 默认有线地址为 `192.168.55.2`，在本机 `http://127.0.0.1:8080/` 提供前端及 API 代理。
地址和存储路径需要按实际设备调整；服务模板中的用户、解释器和模型目录也需按部署环境修改。

当前实机使用 `nano` 用户，前端目录为 `~/yisheng-guardian/frontend/`，
前端、相机和音频路由通过用户级 systemd 服务启动。详见 [Jetson 部署说明](../deploy/jetson/README.md)。

## 音频与情绪观察

ICS43434 的有效左声道映射为 `yisheng_microphone`；网页在内存中做 80 Hz 高通、
20 倍采集增益和限幅，再供录音筛查与数字人语音输入共用。
MAX98357 通过 `yisheng_speaker` 输出网页音频，界面提供 0–100% 音量控制与静音。

情绪标签采用时间相关的指数平滑；首次确认约 0.9 秒，切换需额外持续确认 1.6 秒，
同一标签至少显示 3 秒，短暂人脸丢失宽限 1.2 秒。实际切换延迟还包括平滑和推理耗时。
摄像头标注、主标签和置信度显示共用稳定结果；保留旧标签期间不会把它当作新的负面情绪证据。

## 验证记录

- 后端自动化检查：98 项通过。
- 情绪滤波模拟序列检查：4 项通过，覆盖交替抖动、持续改变、不同帧率及人脸丢失。
- Jetson Chromium 实测：麦克风单声道采集、网页语音编码、筛查 WAV、数字人语音经功放播放。
- 界面实测：390 px 手机宽度和 1366 px 桌面宽度无横向溢出；导航、音量和静音有效。
- 陪伴接口实测：普通生活话题返回 `companionship` 回应。

复现检查：

```bash
node --test deploy/jetson/tests/emotion-filter.test.cjs
cd backend
./mvnw test
```

后端构建需要 Java 17。端侧硬件配置不能仅凭文件检查视为成功，仍需在实际设备上验证。

## 仓库与运行数据

仓库包含源码、静态资源、测试、部署模板和两个小型视觉模型。
`.env`、管理员凭据、用户录音、生成的数字人音频/视频、构建缓存和 `.runtime/` 不提交。
`.runtime/` 包含需要另行下载的较大语音/数字人依赖和模型，具体路径与安装要求见对应服务说明。
在新设备上克隆源码后，需要填写环境变量并准备这些运行依赖，不能把源码仓库直接当作整机镜像。
