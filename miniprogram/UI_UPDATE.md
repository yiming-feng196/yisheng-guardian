## 2026-11-28 布局与交互专项

| 问题 | 定位与处理 |
| --- | --- |
| 键盘收起后布局滞留 | `pages/companion/index.js` 原先在失焦时只清焦点。缺少末次高度事件时，页面继续扣除键盘高度，自定义导航也保持隐藏。现在由同一状态处理组件事件、全局高度回调、失焦、发送、点空白、收起面板和离页。离页移除监听。可用空间按系统视口扣除尚未由系统消化的键盘高度，零高度和失焦都能清除偏移。键盘切换期间保持对话历史挂载。 |
| 欢迎消息首行缩进 | `components/chat-panel/index.wxml` 在保留空白的文本节点中包含模板换行与缩进。消息绑定改为内联，保留消息内容里的换行。气泡统一本身的左右内边距、行高与左对齐。 |
| 窄页面、点击区域与视觉对齐 | `app.wxss` 和 `design/tokens.json` 统一 8/16/24/32rpx 间距、最少 16px 页面边距、至少 44px 的关键触控尺寸、字号、正文行高与玻璃边框。陪伴页和导航共用同一外边线，输入框、发送图标和对话标题重新对齐。顶部继续使用微信原生导航栏与胶囊。 |
| 弹窗确认按钮被挡 | 自定义 Tab 在模拟器中单独绘制，仅提高弹窗层级仍会盖住按钮。记录报告、观察提示、关于和退出确认打开时隐藏 Tab，关闭时恢复。记录弹窗未选中时向字符串属性传空串，清除原先的类型警告。 |
| 切页白闪与布局负担 | 观察、记录、我的移除会重新合成整个页面的入场透明度和位移，页面进出使用微信原生切换。对话收放一次完成布局，内容用位移与透明度过渡。导航、对话和弹窗以半透明底色替代实时背景模糊。数字人继续使用同一静态图像节点，隐藏页暂停未来渲染器适配器。 |
| 服务状态抖动与列表闪烁 | 返回陪伴页原先重复做健康和模型检查，并立即展示“连接中”；进入记录页则先清空列表。陪伴页合并同环境并发检查，成功复用 30 秒、失败复用 5 秒，同环境复查保留上一次实际状态。记录页同环境、同账号复用 15 秒，手动刷新即时重查并保留已有列表，换账号或登出清除旧列表。 |

**动作参数**　`styles/motion.wxss` 使用带轻微回弹的三次贝塞尔曲线。按钮按下 90ms 缩放至 0.975，释放 210ms。聊天内容展开和首页动作区复现约 270ms，最新消息 190ms，底部面板 260ms。按压可随操作反向切换。键盘避让跟随平台高度事件，普通页面和 Tab 使用微信导航，弹窗关闭立即释放操作。支持运行时识别的减少动态效果设置。

**连接浮层**　四个页面、共享组件与小程序资源中未找到黑色的 Connected / View More 控件。此次模拟器截图也未出现该浮层，原截图的工具归属待扫码调试时现场确认。应用顶部的状态来自服务检查或实际问答反馈。

## 公共组件与文件

`app.wxss` 提供颜色、字体、材质、按钮、输入、反馈和间距规则；各页只负责本页布局。`custom-tab-bar/` 提供四等分悬浮导航、安全区域、薄荷选中胶囊、颜色过渡和跳转失败保护。

| 组件 | 职责 |
| --- | --- |
| `components/page-header` | 统一标题、副标题、波形与扩展插槽 |
| `components/status-pill` | 连接/任务状态，文字与圆点共同表达 |
| `components/digital-human` | 独立静态人物展示与未来渲染器接口、缺图降级 |

| `components/setting-row` | 设置图标、标题、说明与右侧操作插槽 |
| `components/empty-state` | 未登录、空数据与错误状态的统一结构 |
| `components/glass-modal` | 可滚动的报告、关于、录音提示与退出确认 |

`utils/ui.js` 统一安全区、导航同步及键盘计算，避免 Android 视口已缩小后再次扣除键盘高度；`utils/records.js` 按后端 `ScreeningTaskStatus` 枚举映射中文标签，保留原始状态。`config/product.js` 集中产品名与版本。`components/environment-notice` 保留给现有集成使用，本轮在各页面用更紧凑的状态文字表达环境。

按钮和玻璃容器采用公共样式，避免仅为一层插槽创建大量包装组件。微信 `style:v2` 图标按钮显式指定尺寸，防止默认按钮宽度挤压输入。

## 运行、兼容与尚未验证

在微信开发者工具导入本目录，直接编译，无需“构建 npm”。首次运行模式取决于 `config/deployment.js` 与已保存偏好；在“我的”切换环境并保存。完整仓库根目录 `start-local.cmd` 启动既有本机后端；密钥继续放后端 `.env`。前端新增第三方运行依赖：**0**。账号注册与手机连接排查见 [手机连接与账号注册](MOBILE_SETUP.md)。素材导出仅开发时使用 Pillow 与可选 Sharp，SVG 可在常见矢量编辑器继续编辑。图标脚本、弥散背景脚本与矢量导出脚本均在 `scripts/`，无需运行它们即可编译前端。

玻璃效果是 WebView 中可落地的半透明/模糊合成，不包含真实折射与光线追踪。背景已预模糊，普通列表避免每项实时滤镜；不支持 `backdrop-filter` 时保留渐变填充、静态环境色与边缘高光。系统减少动态效果会取消非必要过渡；减少透明度时使用较实的底色。

保留微信原生状态栏、标题栏和胶囊，标题字号与顶部背景受原生导航限制；没有绘制假状态栏。自定义 tabBar 在各原生页面中分别创建，首次切换的连续程度受微信页面加载影响。观察准备页在较短屏或大字模式中需要滚动，底部内容已预留导航与安全区。

**尚未验证**：实体 iPhone/Android 的软键盘、VoiceOver/TalkBack、系统大字体、Android不同内核、低性能设备帧率、真实录音/分析、实时3D、手机小程序访问局域网后端的最终状态（手机浏览器已确认健康检查 UP）。发布到手机仍需按微信要求配置合法HTTPS服务域名；本机开发配置不能视为线上部署完成。

## 后续更新：手机连接诊断与真实注册

“我的”增加始终可见的登录/注册入口、账号分段选择、确认密码及表单内错误提示；演示服务不创建账号。注册通过现有 `/user/register` 实际创建普通账号，成功后清空密码并返回登录，重复用户名和非成功响应不会被当作成功。账号与连接异步响应增加环境及操作版本校验。

手机请求在发送前拒绝回环地址，连接错误区分微信域名限制、TLS错误和超时；设置展开区增加本机调试地址按钮、浏览器健康检查地址复制和原始微信错误说明。手机浏览器已由用户确认健康检查返回 UP，本轮无需修改防火墙。公开代码仍使用不含机器 IP 的部署模板，本机预览包由启动脚本生成实际 Wi-Fi 地址。

新版本逻辑测试34项通过；本机真实注册、重复账号、登录及鉴权空记录已使用独立本地测试账号验证。原先“没有提供真实账号”的限制现在仅指用户已有账号与实际健康报告尚未验收；已验证新注册测试账号的完整流程。原始11项界面运行报告和新增注册/连接表单运行报告分别保存在 `design/verification/`，均注明验证范围，不将开发者工具测试称为实体手机小程序验收。
