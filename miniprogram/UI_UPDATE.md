## 公共组件与文件

`app.wxss` 提供颜色、字体、材质、按钮、输入、反馈和间距规则；各页只负责本页布局。`custom-tab-bar/` 提供四等分悬浮导航、安全区域、薄荷选中胶囊、颜色过渡和跳转失败保护。

| 组件 | 职责 |
| --- | --- |
| `components/page-header` | 统一标题、副标题、波形与扩展插槽 |
| `components/status-pill` | 连接/任务状态，文字与圆点共同表达 |
| `components/digital-human` | 独立静态人物展示与未来渲染器接口、缺图降级 |
| `components/chat-panel` | 对话、输入、收放、发送、键盘事件；业务请求仍留在页面 |
| `components/step-progress` | 当前、完成、未完成四步进度 |
| `components/setting-row` | 设置图标、标题、说明与右侧操作插槽 |
| `components/empty-state` | 未登录、空数据与错误状态的统一结构 |
| `components/glass-modal` | 可滚动的报告、关于、录音提示与退出确认 |

`utils/ui.js` 统一安全区、导航同步及键盘计算，避免 Android 视口已缩小后再次扣除键盘高度；`utils/records.js` 按后端 `ScreeningTaskStatus` 枚举映射中文标签，保留原始状态。`config/product.js` 集中产品名与版本。`components/environment-notice` 保留给现有集成使用，本轮在各页面用更紧凑的状态文字表达环境。

按钮和玻璃容器采用公共样式，避免仅为一层插槽创建大量包装组件。微信 `style:v2` 图标按钮显式指定尺寸，防止默认按钮宽度挤压输入。

## 业务和接口

保留原 `/assistant/chat`、`/assistant/status`、`/actuator/health`、`/user/login`、`/api/v1/screenings` 路径和请求协议。保留 UUID、按后端地址隔离的会话、401 清理、环境切换与过期请求防护；密码与模型密钥没有写进小程序。

`config/deployment.js`、本机服务器地址、`project.private.config.json`、后端 `.env` 以及数据库均保持原样。GitHub 与可分发源码包使用仓库既有的公共部署配置，不发布 F 盘的本机专用配置。

## 运行、兼容与尚未验证

在微信开发者工具导入本目录，直接编译，无需“构建 npm”。首次运行模式取决于 `config/deployment.js` 与已保存偏好；在“我的”切换环境并保存。完整仓库根目录 `start-local.cmd` 启动既有本机后端；密钥继续放后端 `.env`。前端新增第三方运行依赖：**0**。账号注册与手机连接排查见 [手机连接与账号注册](MOBILE_SETUP.md)。素材导出仅开发时使用 Pillow 与可选 Sharp，SVG 可在常见矢量编辑器继续编辑。图标脚本、弥散背景脚本与矢量导出脚本均在 `scripts/`，无需运行它们即可编译前端。

玻璃效果是 WebView 中可落地的半透明/模糊合成，不包含真实折射与光线追踪。背景已预模糊，普通列表避免每项实时滤镜；不支持 `backdrop-filter` 时保留渐变填充、静态环境色与边缘高光。系统减少动态效果会取消非必要过渡；减少透明度时使用较实的底色。

保留微信原生状态栏、标题栏和胶囊，标题字号与顶部背景受原生导航限制；没有绘制假状态栏。自定义 tabBar 在各原生页面中分别创建，首次切换的连续程度受微信页面加载影响。观察准备页在较短屏或大字模式中需要滚动，底部内容已预留导航与安全区。

**尚未验证**：实体 iPhone/Android 的软键盘、VoiceOver/TalkBack、系统大字体、Android不同内核、低性能设备帧率、真实录音/分析、实时3D、手机小程序访问局域网后端的最终状态（手机浏览器已确认健康检查 UP）。发布到手机仍需按微信要求配置合法HTTPS服务域名；本机开发配置不能视为线上部署完成。

## 后续更新：手机连接诊断与真实注册

“我的”增加始终可见的登录/注册入口、账号分段选择、确认密码及表单内错误提示；演示服务不创建账号。注册通过现有 `/user/register` 实际创建普通账号，成功后清空密码并返回登录，重复用户名和非成功响应不会被当作成功。账号与连接异步响应增加环境及操作版本校验。
