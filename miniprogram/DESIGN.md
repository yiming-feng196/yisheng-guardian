# 忆声智护界面规范

四页共享雾蓝、冰蓝、浅薰衣草与奶油色空间背景；局部蜜桃暖光；品牌绿色只用于主要交互、状态与导航。实现与验收说明见 [UI_UPDATE.md](UI_UPDATE.md)，参数见 [design/tokens.json](design/tokens.json)。

- 首页以原有静态数字人为中心，保留问候、三项快捷话题和可展开聊天；折叠不清空对话。语音与实时3D尚未实现，当前隐藏麦克风按钮。
- 玻璃由独立背景、半透明渐变、白色边缘与轻微阴影构成；主要浮层与导航使用可用时的背景模糊。降级时仍保留预模糊氛围，不依赖折射或大量实时滤镜。
- 393px基准：标题约28px、名称32px、问候24px、正文16px、按钮17px、辅助14px、状态13px、导航12px。大字模式增加约25%，窄屏正文不小于16px，话题可换行，必要时滚动。
- 统一四项悬浮玻璃导航；内容根据真实安全区预留空间，键盘弹出时隐藏导航，避免重复避让。主要操作至少44px可点区域。
- 按压120ms、页面220ms、导航240ms、聊天280–300ms；减少动态效果时停用非必要过渡。静态数字人不伪装眨眼、口型或正在录音。
- 观察为四步流程体验，不采集音频，不产生健康评分；记录只展示后端真实数据或明确标记的演示数据；账号与数字伙伴身份分开。
- 服务器配置折叠；环境变化明确保存；大字模式即时保存但不提交其他草稿；退出账号需确认。

设计过程参考本机 apple-design、emil-design-eng、mobile-native 技能和用户提供的四张图片。原人物、Logo与任务图片沿用项目；新插图与SVG源文件、参考图、来源说明及可下载素材包均在 [design/](design/README.md)。
