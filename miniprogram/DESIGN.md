# 忆声陪伴界面规范

本轮方向：iOS 风格的数字人陪伴界面。优先服务于日常陪伴、清晰阅读和可预测的操作。

- 首页只呈现数字人、简短问候、快捷话题和输入栏。点击形象、输入框或快捷话题展开对话；收起面板不清空消息，不取消正在进行的请求。顶部仅显示一个可点按的服务状态。
- 玻璃材质仅用于聊天面板和输入栏。问候文字使用正常文档流，避免绝对定位的操作覆盖文字。保持深色文字及较高底色不透明度；减少透明度或增强对比度时使用实底。
- 使用系统字体、大标题、分组列表、固定四项原生导航。原生导航处理设备底部安全区域，内容不重复添加同一安全区留白。
- 默认文字 34rpx，大字模式 42rpx。长名称、错误、消息可以换行，主操作与图标按钮至少保留 44px 点击高度。
- 点按立刻反馈，功能在手指抬起后执行。使用 120ms 的轻微按压反馈，对话面板沿相同路径以 220ms 展开/收起，可随时反向切换；减少动态效果时去除位移动效。聊天与页面内容不添加装饰性循环动画。
- 保留演示标记、未开放功能提示、登录和网络失败反馈。当前数字人是原项目静态形象，不表示麦克风正在监听，不模拟语音或口型视频已接入。
- 小程序仍使用原生 WXML/WXSS/JavaScript，没有引入 Web 框架或运行依赖。玻璃模糊、软键盘避让和原生安全区域需在微信真机核验。
- 微信 `style: v2` 的按钮默认尺寸不能按浏览器 button 推断。自定义按钮显式使用 `size="mini"`；发送按钮固定为 44px。原生 input 放在独立的可伸缩容器内，宽度为 100%，不再把原生输入组件设成 width:0。
- “我的”仅保留账号和常用偏好，服务器地址通过“服务连接”展开；实现细节和未开放能力按需在“关于忆声”中说明。医疗提示保留在相关真实回复中。

设计参考：Emil Kowalski 的 apple-design、mobile-native、emil-design-eng 技能及 Apple Human Interface Guidelines。

素材：数字人沿用 backend/src/main/resources/static/avatar-hero-v1.png；Logo 沿用原项目。仅作显示尺寸与编码优化。assets/icons 为本轮代码绘制的原创线性图标；可通过 scripts/export-ui-assets.py 重新导出（开发时需要 Pillow 和完整仓库）。
